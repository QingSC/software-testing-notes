# practice.html 手工测试用例

> 针对 `pages/practice.html` 页面的手工测试用例，用于练习测试用例设计方法。

---

## 用例设计方法说明

本文件使用以下几种黑盒测试用例设计方法：

| 方法 | 说明 | 示例 |
|---|---|---|
| 等价类划分 | 把输入分成有效类和无效类，每类选一个代表测试 | 用户名：有效（admin）、无效（空） |
| 边界值分析 | 测试边界点及其附近值 | 密码长度为 6 位、0 位、超长 |
| 错误推测法 | 根据经验预测容易出错的地方 | 密码输入特殊字符 |
| 场景法 | 模拟用户完整操作流程 | 登录 → 选择城市 → 提交评论 |

---

## 用例字段说明

| 字段 | 含义 |
|---|---|
| 用例编号 | 唯一标识，格式：模块-序号 |
| 用例标题 | 简明描述要测什么 |
| 前置条件 | 执行该用例前需要满足的状态 |
| 测试步骤 | 详细操作步骤 |
| 预期结果 | 执行后应该看到的结果 |
| 优先级 | P0（核心）/ P1（重要）/ P2（一般） |
| 设计方法 | 使用的用例设计方法 |
